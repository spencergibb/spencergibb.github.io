I'm Spencer Gibb, co-founder and lead of [Spring Cloud](https://github.com/spring-cloud). I work on open source software at Broadcom, following the team's time at Pivotal and VMware. I'm based in Ann Arbor, Michigan.

My work centers on Java, Spring, and distributed systems: building tools that help developers connect services and manage the complexity that comes with them.

## Work & open source

- **[Spring Cloud](https://spring.io/projects/spring-cloud):** tools for common patterns in distributed systems, built on Spring Boot.
- **[Spring Cloud Gateway](https://spring.io/projects/spring-cloud-gateway):** an API gateway for routing requests and applying cross-cutting behavior to APIs.

I've also contributed to Spring Framework, Spring Boot, and Netflix Eureka. Earlier in my career, I worked on everything from large data systems to developer tools and web applications.

## Speaking & writing

I speak at conferences and user groups about Spring Cloud, API gateways, Java, and distributed systems. You can find recordings and slides in my [presentations](/categories/presentations/).

On this site, I [write](/post/) about software, open source work, conference visits, and the tools I use, including [what's on my desk](/blog/2024/12/30/whats-on-my-desk/).
